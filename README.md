# StakeLab：Web3 质押管理台

从零构建的求职作品。目标是展示钱包连接、链上读取、合约交互、交易反馈、测试和部署的完整交付能力。当前为第一个里程碑：连接浏览器钱包，识别网络，读取 Base Sepolia 测试网余额。

## 本地运行

环境：Node.js 22.12+ 或 20.19+，npm，支持 EVM 的浏览器钱包。

```powershell
npm install
npm run dev
```

打开终端显示的本地地址。点击“连接钱包”；如果钱包处于其他网络，点击“切换到测试网”。只使用测试钱包和测试币，切勿输入私钥或助记词。

## 当前架构

- React + TypeScript + Vite：前端应用
- Wagmi + Viem：钱包和链上读取
- TanStack Query：异步数据缓存
- Base Sepolia：开发测试网络

## 里程碑与验收

详细安排见 [ROADMAP.md](./ROADMAP.md)。第一阶段验收：应用可启动；连接和断开钱包可用；地址、网络与测试网余额正确显示；错误网络提示明确；无钱包时页面可理解；`npm run build` 通过。

## 项目边界

这是学习与作品展示项目，尚无质押合约，也没有真实资金功能。后续合约上线测试网前须完成测试和人工代码审查。
